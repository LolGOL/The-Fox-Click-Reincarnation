# 🦊 The Fox Click Reincarnation

Мрачный инкрементальный кликер (кликер с элементами сюжетного киберпанка и хоррора), разработанный на движке **Godot 4**.

## ⚙️ Особенности игры
* **Терминальный интерфейс Fox OS:** Полностью кастомный UI в тёмно-багровых тонах с CRT-эффектами и глитчами.
* **Эволюция Лиса-компаньона:** Верный зверь сидит рядом с центральной печатью, реагирует на клики и меняет форму вместе с ростом фаз симуляции.
* **Система мицелия и мутаций:** Заражай систему, выбирай штаммы развития и управляй пассивным доходом.
* **Динамические фоны и звук:** Процедурный саунд-дизайн на `AudioStreamGenerator` и смена фоновых тиров от подворотни до цифровой сингулярности.
* **Сюжетный финал:** Достигни 16-й фазы («Истинный Ноль»), сломай матрицу и освободи Лиса.

## 🛠️ Технологии
* **Движок:** Godot 4.x (GL Compatibility / Jolt Physics)
* **Язык:** GDScript
* **Архитектура:** Модульная система автозагрузок (`GameState`, `Economy`, `Audio`, `Achievements`, `FoxSettings`)

2. Клонируйте репозиторий:
